# RR Pharmacy

A responsive, catalogue and enquiry website for RR Pharmacy, a wholesale medical agency in Kurnool. Built with Next.js App Router, React, and TypeScript. No database or paid service is needed to run the current site.

## Run locally

Install Node.js 20.9 or newer and pnpm, then from this folder run:

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. To make a production build, run `pnpm build`, then `pnpm start`. `pnpm lint` checks the source with ESLint. npm is also supported if preferred.

## Add or update products

Edit [`data/products.json`](./data/products.json). It is currently empty so the website does not make up medicine names or product details. Add an object for each approved catalogue item:

```json
[
  {
    "name": "Business-approved product name",
    "slug": "business-approved-product-name",
    "category": "Tablets",
    "productType": "Optional type",
    "description": "Optional factual description supplied by the business.",
    "image": "/images/product-image.webp",
    "featured": true,
    "active": true
  }
]
```

Use unique URL-safe slugs. Put images in `public/images/` and reference them with a path beginning `/images/`. Set `active` to `false` to hide an item and `featured` to `true` to show it on the home page. Valid categories are currently listed in `lib/business.ts`; update that file to change the category cards and filter options. Product prices are not part of the public product data or UI.

## WhatsApp and contact

The business phone, international WhatsApp number, owner, address, and hours are centralized in `lib/business.ts`. WhatsApp link creation is in `lib/whatsapp.ts`. The contact form validates in the browser and opens WhatsApp with the submitted details; it does not claim to store or email enquiries.

## Environment

Set `NEXT_PUBLIC_SITE_URL` to the real deployed canonical origin before production so metadata, robots, and sitemap use your domain. For local development it can be omitted. `.env.example` shows the format with a placeholder domain.

## Deployment

Deploy as a Next.js application on Vercel: import the repository, use the default Next.js build settings, and optionally set `NEXT_PUBLIC_SITE_URL` to the production domain. A database and admin login are intentionally not included. Keep product changes in the reviewed JSON catalogue until an authenticated content-management backend is commissioned.

## Pages

Home, product catalogue, product details, About, Contact, Privacy Policy, Terms & Conditions, and a 404 page. SEO metadata, `robots.txt`, and `sitemap.xml` are generated by the app. Public pages do not show product prices. Product information carries a medical disclaimer and does not provide medical advice.
